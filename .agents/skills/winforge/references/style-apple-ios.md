## 2. 设计灵魂与 Liquid Glass 27 光学精修

- **内容永远是主角**：液态玻璃只用在**通边侧边栏、悬浮工具栏、导航胶囊、浮层卡片、控制中心与灵动岛**上；大段文字阅读区与高密度数据表保持干净低干扰的底层面板，绝不把整屏糊成发灰毛玻璃。
- **27 代光学精修四大要素**：
  1. **均匀柔焦与饱和度提亮（Uniform Refraction）**：背景透过玻璃时折射均匀干净，边缘无脏灰光晕（`backdrop-filter: blur(...) saturate(185%)`）；
  2. **高对比度自适应薄膜（Improved Contrast）**：根据浅色/深色背景自动拉稳文字对比度（正文 ≥ `4.5:1`），复杂壁纸或滚动内容经过玻璃下方时文字依然锐利；
  3. **1px 顶部/内缘镜面折射高光**：顶部最亮、四周细腻收束，呈现真实玻璃倒角厚度；
  4. **无级透度自定义（Ultraclear ↔ Fully Tinted）**：支持用户在**超清透（Ultraclear）→ 均衡标准（Standard）→ 全染色高实底（Fully Tinted）**之间连续滑动微调，兼顾极致通透爱好者与高对比办公用户。
- **丝滑连续几何与锐利图标**：大圆角与严格嵌套圆角相呼应；图标采用更清晰精致的分层细节与统一线宽，避免糊成一团。

## 3. Windows 桌面端专属适配规范

- **一体化融合顶栏 + 统一工具条（Uniform Toolbar）**：
  - 隐藏 Windows 原生标题栏，背景与通边侧栏直通窗口顶边（顶栏高 `46px–52px`，空白区设为 `app-region: drag`，所有交互控件设为 `no-drag`）。
  - 工具栏按钮高度（`32px`）、圆角（`999px` 或 `10px`）、图标尺寸（`15px–16px`）与间距（`6px–8px`）保持严格统一。
- **通边液态玻璃侧边栏（Edge-to-Edge Sidebar）**：
  - 多页面/管理类桌面软件优先采用左侧通顶通底的半透明液态玻璃侧栏（宽 `210px–240px`），底层柔和环境光与内容边缘可微微透出；工具/轻量小窗则可切换为底部居中悬浮液态玻璃导航胶囊。
- **精修右上角 Windows 窗口控制按钮**：
  - 保留右上角 **最小化 / 最大化 / 关闭**，彻底重绘为 `32px × 28px`、圆角 `8px`、间距 `4px`、距边缘留 `8px` 呼吸感的圆润图标按钮；关闭键悬停柔和亮起 Apple 柔红（`#FF3B30` / `#FF453A`）配纯白线条，点击带轻柔回弹。
- **字体与图标（100% 离线内置）**：
  - 随包离线内置贴近 San Francisco + 苹方的免费商用字体（英文数字 `Inter` / `Plus Jakarta Sans` + 中文 `Source Han Sans SC` / `HarmonyOS Sans SC`），回退链：`"SF Pro Display", "Inter", "Segoe UI Variable", "Microsoft YaHei UI", sans-serif`。
  - 数值统一启用 `font-variant-numeric: tabular-nums`。
  - 图标采用 **1.75px–2px 圆头圆拐角矢量 SVG**（分层细腻清晰），**严禁使用系统 Emoji**。

## 5. 圆角嵌套、间距与字号阶梯

- **嵌套圆角铁律**：`外层圆角 = 内层圆角 + 内边距`（例：外层卡片 `22px`、内距 `8px` → 内嵌块 `14px`）。
- **圆角基准**：
  - 窗口与大浮层卡片：`20px – 24px`
  - 独立导航胶囊 / 主操作按钮 / 工具胶囊：`999px`
  - 侧边栏选中行 / 输入框 / 矩形控件：`10px – 12px`
  - 迷你徽章 / 物理键帽：`6px – 8px`
- **字号阶梯**：页面主标题 `22px–26px (600, -0.025em)` → 区块标题 `15px–16px (600)` → 正文/按钮 `13.5px–14px (400/500, 行高 1.5)` → 辅助说明 `12px`。
- **呼吸留白**：严格按 `4 / 8 / 12 / 16 / 24px` 递增，卡片内边距不少于 `16px–20px`。
