# Apple / 最新 iOS & macOS 液态玻璃设计体系（1:1 复刻指南）

本手册用于 1:1 复刻苹果最新系统（iOS 液态玻璃 Liquid Glass + macOS 桌面级克制美学）的视觉质感、空间层级、控件手感与动效物理，并优雅适配 Windows 桌面端操作习惯。

> **实体参考**：动工前务必打开并对照 [Apple 液态玻璃交互样板间](../showcases/apple-liquid-glass.html)，直接参考其中的玻璃合成、内缘高光、圆角嵌套、按钮按压与弹簧动效实现。

---

## 1. 设计灵魂与核心气质

- **通透但克制**：内容永远是主角，液态玻璃只用在**悬浮导航栏、工具胶囊、浮层卡片、灵动岛状态条与临时弹层**上；大段文字阅读区与复杂列表保持干净低干扰的底面，绝不把整屏糊成看不清字的重度毛玻璃。
- **光学真实感**：真正的 Apple 玻璃不是“半透明白框 + 模糊”，而是由四层光学结构共同构成的：
  1. **背景柔焦与饱和度提亮**（`backdrop-filter: blur(...) saturate(180%)`）；
  2. **克制的色调薄膜**（浅色清透乳白，深色微透炭灰）；
  3. **1px 顶部/四周模拟折射的内缘高光**（顶部最亮、边缘柔和衰减，营造玻璃切面折射感）；
  4. **大半径极柔环境阴影**（让玻璃自然“浮”在内容之上，而非黑乎乎的脏阴影）。
- **丝滑连续几何**：大圆角与精确的嵌套圆角关系，视觉上如鹅卵石般温润流畅，没有任何突兀的尖角或杂乱细碎的分割线。

## 2. Windows 桌面端专属适配规范

- **一体化融合无边框顶栏**：隐藏 Windows 丑陋的原生白/黑标题栏，让背景与界面铺满整个窗口（顶栏高度 `44px–48px`，空白区域设为窗口可拖拽区 `app-region: drag`，所有按钮和输入框设为 `no-drag`）。
- **精修右上角 Windows 窗口控制按钮**：尊重 Windows 用户肌肉记忆，保留右上角 **最小化 / 最大化 / 关闭** 三个图标按钮，但必须彻底重绘：
  - 尺寸：`32px × 28px` 或 `34px × 28px`，圆角 `8px`，彼此间距 `4px`，距窗口右上边缘留 `8px` 呼吸感（绝不做成贴死窗口顶角的直角块）。
  - 图标：细匀圆头 SVG 线条（线宽 `1.5px`），静置柔和中性灰；悬停浮起轻微玻璃底板；关闭按钮悬停柔和亮起 Apple 风格柔红（`#FF3B30` / `#FF453A`）配纯白图标，点击有轻柔回弹。
- **字体与图标（100% 离线内置，绝不依赖目标电脑环境）**：
  - 优先随安装包离线内置免费商用、气质最贴近 San Francisco + 苹方的字体组合（英文数字 `Inter` / `Plus Jakarta Sans` + 中文 `Source Han Sans SC` 思源黑体或 `HarmonyOS Sans SC`），并写好优雅回退链：`"SF Pro Display", "Inter", "Segoe UI Variable", "Microsoft YaHei UI", sans-serif`。
  - 数字采用等宽表格数字 `font-variant-numeric: tabular-nums`，倒计时、进度、大小数值跳动时不抖动。
  - 图标统一采用 **1.75px–2px 圆头圆拐角线性矢量 SVG**（贴近 SF Symbols 视觉重量），严禁混用粗细不一的图标，**严禁使用 Emoji**。

## 4. 圆角嵌套、间距与字号阶梯

- **嵌套圆角铁律**：`外层圆角 = 内层圆角 + 内边距`（例如外层卡片圆角 `22px`、内边距 `8px`，里面紧贴的按钮或子块圆角就用 `14px`），视觉贴合度瞬间拉满。
- **常用圆角基准**：
  - 主窗口大卡片 / 浮层弹窗：`20px – 24px`
  - 独立玻璃工具栏 / 导航胶囊 / 药丸按钮：`999px`（全胶囊）
  - 常规矩形按钮 / 输入框 / 列表选中行：`10px – 12px`
  - 迷你徽章 / 快捷键键帽：`6px – 8px`
- **字号阶梯**：
  - 页面主标题：`22px – 26px`，字重 `600`，字距 `-0.02em`
  - 卡片标题 / 区块名：`15px – 16px`，字重 `600`
  - 正文与按钮文字：`13.5px – 14px`，字重 `400`（按钮 `500`），行高 `1.5`
  - 辅助说明 / 时间标签：`12px`，字重 `400`
- **呼吸留白**：基础网格按 `4px / 8px / 12px / 16px / 24px` 递增；卡片内边距不少于 `16px–20px`，页面四周保留充足呼吸区。

## 5. 核心控件与动效参数（1:1 手感）

| 元件 | 静态与悬停 | 按压 / 切换动效 |
|---|---|---|
| **液态玻璃悬浮导航胶囊** | 整条悬浮于顶部或底部，内含滑动高亮“玻璃水滴指示器” | 切换选中项时，玻璃滑块沿路径平滑滑移并瞬间轻微横拉（`scaleX(1.08)`），到位后用弹簧曲线 `cubic-bezier(0.32, 1.18, 0.42, 1)` 在 `320ms` 内柔和回弹 |
| **主操作按钮（实心胶囊/圆角）** | 顶边叠加微弱白光梯度；悬停轻提亮 + 极微上浮 `translateY(-0.5px)` | 按下 `80ms` 内缩至 `scale(0.965)`，松手 `220ms` 弹性回正；高频点击可随时打断接续 |
| **玻璃次级按钮** | 半透明玻璃底板 + 内缘高光；悬停柔和提亮底色并点亮边缘高光 | 按下 `scale(0.965)` + 玻璃略微加深，松手利落回弹 |
| **iOS 风格开关（Switch）** | 宽 `46px` 高 `26px` 胶囊轨；白色圆形滑块带极柔底影 | 按住未松手时圆形滑块横向微拉长（宽 `22px → 26px`），松手瞬间沿轨道弹簧滑移并恢复正圆，轨道色 `220ms` 平滑过渡 |
| **精致滑块（Slider）** | 细圆轨道（默认 `5px` 高），悬停或拖动时轨道微微变厚至 `7px` | 拖动全程 100% 实时跟手无延迟，数值以等宽数字实时跳动 |
| **灵动岛状态胶囊（Dynamic Pill）** | 空闲时紧凑居中悬浮显示精简状态图标与 2–4 字摘要 | 有进行中任务、提示或点击时，从自身锚点平滑舒展变形为圆角详情浮卡（`340ms` 弹簧），完成后优雅收拢 |
| **分段控制器（Segmented Control）** | 柔和凹槽底板 + 纯白/亮灰悬浮滑块 | 切换时滑块平滑滑移到位，文字字重与明度同步过渡 |
| **弹窗与菜单（Sheet / Popover）** | 菜单从触发按钮锚点轻盈展开（`scale(0.92) → 1` + 淡入，`200ms`）；重要确认弹窗配轻微背景柔暗遮罩 | 按 `Esc` 或点击外部即刻流畅收起并恢复焦点 |
