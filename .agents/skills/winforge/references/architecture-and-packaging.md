# 程序架构选型与“新电脑装完即用”离线打包铁律

本手册解决两个核心工程问题：
1. 根据软件需求选出**最稳、最容易做出 1:1 Apple / OriginOS 顶级颜值、Vibe Coding 成功率最高**的技术架构；
2. 死守底线：**打包出来的 `.exe` 在一台刚买的新 Windows 电脑上（哪怕断网、没装任何开发环境），安装完直接就能用，绝不弹窗要求额外下载任何东西。**

---

## 1. 智能架构选型指南（大白话向用户提案）

每次新项目动工前，AI 根据需求从下面三条成熟路线中选出 **1–2 个最合适的方案**，用通俗语言讲清优缺点让用户拍板：

| 路线 | 最适合做什么软件 | 颜值与动效还原度 | 零额外下载表现 | 安装包体积 |
|---|---|---|---|---|
| **① Electron（React / Vue / 纯前端 + TypeScript）** | **绝大多数带高颜值界面的桌面软件（默认首选）**：效率工具、笔记/整理工具、媒体播放器、悬浮小组件、看板、AI 客户端等 | **顶级（100% 还原）**：CSS/SVG/Web 动效把 Apple 液态玻璃、OriginOS 光影原子、物理弹簧还原到极致，AI 写代码最稳、踩坑最少 | **满分（绝对 100% 离线）**：把完整渲染内核直接打进软件，任何 Win10 / Win11 断网也能装完即用 | 偏大（约 70–100 MB） |
| **② Tauri v2（Rust + 前端界面）** | **看重极小安装包体积与极低内存占用的现代工具**（且主要面向 Windows 11，或愿意随包内置离线 WebView2） | **顶级（98% 还原）**：界面同样是前端技术，液态玻璃与弹簧动效同样丝滑 | **Win11 天然免下载**；若需兼容无网老 Win10，必须开启离线内置 WebView2 打包模式 | 极小（约 6–15 MB；若内置离线内核则接近 Electron） |
| **③ C# 自包含（WPF / WinUI 3，.NET Self-Contained）** | **深度控制 Windows 底层、硬件监控、无复杂花哨动画的系统实用小工具** | **中等**：做复杂 Apple 液态玻璃折射与 OriginOS 原子岛形变难度高，AI 容易写出样式兼容问题 | **开启自包含后免下载**：必须配置 `SelfContained=true`，把 .NET 运行时完整塞进安装包 | 中等（约 30–70 MB） |

> **选型口诀（给 AI）**：
> - 只要用户的软件**核心卖点是高颜值 Apple / OriginOS 界面与丝滑交互**，优先推荐 **Electron**（最稳、绝对零环境坑），若用户特别在意“软件体积要非常小”且主要用 Win11，则推荐 **Tauri**。
> - 尽量**不推荐 Python（PyQt / Tkinter / PyInstaller）**做面向新电脑分发的高颜值桌面软件：不仅很难做出真正的液态玻璃与物理弹簧质感，打包出的单文件还极易启动慢、被杀毒软件误报或漏带 DLL。只有用户明确要做纯 Python 本地算法脚本壳子时才考虑，且仍须彻底解决离线依赖。

## 2. “新电脑装完即用、零额外下载”铁律

### 交付形态标准
- **默认交付**：**标准离线一键安装版 `Setup.exe`**（如 Electron 使用 `electron-builder` 的 `nsis` 离线打包，Tauri 使用 `nsis`，C# 使用 Inno Setup / Wix 离线打包）：
  - 允许用户一键安装，也支持自定义安装路径；
  - 自动创建桌面快捷方式与开始菜单入口；
  - 支持在 Windows“已安装的应用 / 控制面板”里一键干净卸载；
  - 安装包统一输出到项目根目录的 `release/` 文件夹下。
- **按需交付**：当用户明确提出“要绿色版 / 免安装版 / 拷 U 盘用”时，改为或额外打包便携单文件 `.exe` / 解压即用压缩包（并将用户数据存放在程序同级 `data/` 目录）。

### 绝对禁止事项
- ❌ **严禁使用在线联网安装器**（比如 2 MB 壳子点开后联网下主程序，或默认调用 WebView2 在线 bootstrapper）。
- ❌ **严禁依赖目标电脑预装任何环境**：禁止假定用户电脑有 Node.js、Python、.NET Desktop Runtime、VC++ Redistributable、Java 或特定字体。
- ❌ **严禁外链加载界面资源**：严禁在界面里用 `<link href="https://fonts.googleapis.com/...">` 或外部 CDN 加载字体、图标、CSS、JS——一旦新电脑没网或连不上外网，整个软件就会字体错乱或白屏！所有字体、图标、依赖库必须 100% 离线打包进程序内部。

## 3. 各路线离线打包关键配置要点

- **Electron（`electron-builder`）**：
  - 使用 `nsis` 目标，开启 `oneClick: false` + `allowToChangeInstallationDirectory: true`（可选路径的现代安装向导），或按需开启简洁一键安装；
  - 提前把本地字体、图标等静态资源配置进打包资源列表（`files` / `extraResources`），打包后用生产路径加载，禁止引用开发期 `localhost`；
  - 窗口创建时先设 `show: false`，等 `ready-to-show` 事件触发后再显现窗口，彻底消灭打开瞬间的白屏闪烁；
  - 启用安全默认项：`contextIsolation: true`、`nodeIntegration: false`，通过精简的 `preload` 暴露有限能力。
- **Tauri v2**：
  - 若目标仅限 Win11，系统已原生内置 WebView2；若要确保老旧 Win10 断网也 100% 装完即用，在 `tauri.conf.json` 中显式配置 `webviewInstallMode` 为 `offlineInstaller` 或 `embedBootstrapper`（优先离线嵌入，绝不用 `downloadBootstrapper`）；
  - 明确配置无边框自定义窗口与拖拽区权限。
- **C#（.NET 8+）**：
  - 发布命令强制携带 `--self-contained true -r win-x64`（需要单文件绿色版时加 `-p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true`），确保新电脑绝不弹窗索要 `.NET Desktop Runtime`。

## 4. 打包交付前“新电脑防翻车”自检清单

每次打包交付给用户前，AI 必须逐项核对并如实向用户汇报结果：
1. **断网可跑**：界面里零外链字体/图标/CDN，所有视觉素材均已离线内置。
2. **零本机路径写死**：代码里不存在 `C:\Users\具体用户名\...` 或硬编码的绝对路径，全部使用系统标准路径接口。
3. **写权限安全**：用户设置、缓存、数据库一律存放在 `AppData\Roaming\<软件名>`（绿色版存程序同级 `data/`），**绝不**往只读的 `C:\Program Files\` 安装目录里写文件导致普通用户一打开就闪退。
4. **高分屏清晰不糊**：在 125% / 150% / 200% Windows 缩放下文字锐利、窗口尺寸合理、按钮不被裁切。
5. **优雅关闭无残留**：点右上角关闭窗口后，后台进程、计时器与托盘图标干净退出，不偷偷占着内存导致卸载或覆盖安装时提示“文件被占用”。
6. **关于 Windows SmartScreen 提示**：由于个人开源/自用软件通常没有昂贵的商业代码签名证书，在新电脑首次双击安装时，Windows 可能会弹出蓝色的“已保护你的电脑”提示。交付时用大白话提前告知用户：“这是没有花钱买商业证书的正常系统提示，点‘更多信息 → 仍要运行’即可”，同时提供安装包的哈希校验说明，绝不教用户关闭系统杀毒软件。
