## 1. 设计灵魂与 OriginOS 7 核心基因

- **Dynamic Translucent Material（三档动态半透明材质）**：OriginOS 7 不再只有单一磨砂卡面，而是根据背景光影自适应呈现分层深度，并提供三档官方质感风格供用户或产品定位选用：
  1. **Realistic（拟真通透）**：通透度最高、边缘镜面高光最明显，底层自然光斑与景深层次一览无余；
  2. **Natural（自然平衡，默认）**：如温润白瓷 / 深釉般的半透质感，颜值与长时间读写舒适度最佳平衡；
  3. **Soft（柔和磨砂）**：高柔焦、低对比干扰的丝绒雾面，最适合长文阅读、专注记录与护眼场景。
- **Dynamic Glow（实时交互光晕 / 光随手走）**：点击、悬停、滑动、切换控件时，柔和的环境光斑实时追随光标与交互落点自然流动；按下按钮或卡片瞬间从触点泛起极轻柔的柔光微涟漪，让界面有“活着的光感”而非死板静态色块。
- **Fluid Motion + 速度感知弹簧 + 无缝打断**：
  - **水滴分离与融合（Fluid Motion）**：底部导航气泡滑动、原子岛舒展收拢、卡片合并展开时，呈现如水滴般柔和拉伸再丝滑落位的流动感；
  - **速度感知弹簧（Velocity-Aware Spring）**：快速切换或拖滑时回弹干脆利落，慢速轻推时阻尼更温润绵软；
  - **无缝打断（Seamless Interaction）**：横纵滚动切换或动画播到一半反向点击时，永远从当前画面实时接续，绝不瞬移卡顿。
- **Origin Workbench（多任务卡片工作台）**：桌面端核心效率范式——允许在一个主窗口内同时挂起多个活动任务/子面板，以清晰卡片槽位呈现，一点即切换、彼此状态互不干扰，切来切去依然丝滑。
- **Origin Island + Snap & Go（主动情景原子岛）**：顶部居中原子岛不仅显示进度脉冲与专注计时，还能在用户拖入文件、截屏或复制关键内容时主动识别上下文，直接展开一键情景操作（如“一键归档”“提取待办”“添加提醒”）。
- **Immersive Home 昼夜光影 + Nighttime Eye Protection 4.0（夜间智能护眼）**：白天图标与原子卡清澈鲜活；夜间深色模式自动切入柔和深空光晕，并支持**夜间护眼 4.0**——柔化刺眼亮色与纯白高光，同时提升暗部文字与层级边线的清晰度。

## 2. Windows 桌面端专属适配规范

- **全景光影融合顶栏**：背景弥散晨光/深空光晕直通窗口最顶边（顶栏高 `48px–54px`），右上角保留精修的圆润 Windows 窗口控制按钮（圆角 `10px` 微浮胶囊风格，关闭键悬停亮起柔和暖珊瑚红 `#F2555A` 配纯白线条），兼顾 Windows 肌肉记忆与第一眼高级感。
- **字体与图标（100% 离线内置）**：
  - 优先随包离线内置气质最贴近 vivo Sans 的圆润现代无衬线字体（英文数字 `Plus Jakarta Sans` / `Inter` + 中文 `HarmonyOS Sans SC` / `Source Han Sans SC`），平滑回退至 `"Segoe UI Variable", "Microsoft YaHei UI", sans-serif`。
  - 原子卡片上的核心大数字（专注倒计时、进度百分比、文件计数）采用清朗字重 `600` + 等宽对齐 `font-variant-numeric: tabular-nums`。
  - 图标采用**温润微弧度、填充与线性克制结合的矢量 SVG**，白天清澈、夜间自带柔和立体微光，**严禁使用系统 Emoji**。

## 4. 原子几何比例与空间节奏

- **饱满圆润的大圆角基因**：
  - 原子功能卡片 / Workbench 任务卡：`24px – 28px`
  - 原子岛 / 悬浮导航条 / 主操作胶囊按钮：`999px`
  - 卡片内嵌图标块 / 阻尼推杆：`14px – 16px`（严守 `外圆角 = 内圆角 + 间距`）
  - 输入框与次级按钮：`12px – 14px`
- **网格与信息留白**：
  - 原子 Bento 网格支持 `1×1` 小卡、`2×1` 宽卡、`2×2` 主焦点卡，卡片间距统一 `14px – 16px`，卡片内边距 `18px – 22px`；
  - 每张卡片坚持**一眼直达**原则（左上图标/状态 + 核心大数字或单手操作），绝不往一张小卡里硬塞五六个按钮。

## 5. 核心控件与 Q 弹物理动效参数（1:1 手感）

| 元件 / 范式 | 视觉与交互状态 | OriginOS 7 物理动效 |
|---|---|---|
| **Dynamic Glow 交互光晕** | 卡片与按钮表层叠独立柔光层，随光标实时移动定位 | 悬停 `200ms` 渐显柔光；点击瞬间在触点泛起柔和低饱和光波并 `380ms` 消散，绝不做成高饱和霓虹圈 |
| **原子卡片原位放大（FLIP）** | 悬停柔和上浮 `translateY(-3px)`；点击从原卡片坐标原位放大展开详情 | `380ms` 弹性曲线 `cubic-bezier(0.22, 1.12, 0.36, 1)` 原位展开；关闭或按 `Esc` 沿原路丝滑弹回原格 |
| **Origin Workbench 工作台** | 同屏展示多个活跃任务卡（带实时缩略状态与轻量切换栏） | 点击任一任务卡，在 `320ms` 内丝滑切至主工作焦距，原任务退入侧/顶工作台槽位并保持状态不刷新 |
| **原子岛 + Snap & Go** | 顶部居中墨釉胶囊，带柔和脉冲状态点 | 触发情景事件（拖文件/截图/状态更新）时 `360ms` 弹性形变展开一键情景动作，完成后自动优雅收回 |

| **水滴悬浮导航胶囊** | 独立玻璃胶囊底座，选中项带高亮柔光气泡 | 切换时高亮气泡沿路径滑移并伴随轻微水滴横向拉伸，到位轻弹落位，图标轻微弹跳 `translateY(-3px)` |
| **厚胶囊阻尼推杆** | 宽厚圆角大胶囊填充（高 `44px`，圆角 `16px`），类似系统亮度/音量条 | 拖动 100% 实时跟手无滞后，滑到两端给轻微弹性视觉阻尼，松手后恢复平滑过渡 |

## 6. 个性化趣味风味（From You, For You — 克制可选）

OriginOS 7 官网的个性化趣味设计（**Glint Theme / Wiggle Theme / StickIt / Pet Pals**）在 Windows 桌面软件中定位为**“受控的可选装饰风味”**：
- **默认不启用**：严肃效率、文档整理、财务/开发类工具默认保持纯净光影原子风格，不擅自加入趣味元素。
- **何时启用**：仅当用户明确想要更轻松、有温度、带个性化氛围的软件（如番茄钟陪伴、音乐播放器、手账/灵感墙、个人桌面挂件）时主动提案，并始终提供**一键关闭开关**：
  - **Glint 微光（视角流光）**：光标划过主题封面或纪念徽章时，叠加极低不透明度（`≤ 15%`）的柔和斜向光泽掠过，营造立体卡片质感；
  - **Wiggle 轻涟漪**：点击封面或专注完成庆祝时，给局部容器一次极轻柔的果冻微弹或水波扩散（时长 `≤ 450ms`，绝不全屏乱晃）；
  - **StickIt / 微状态伙伴**：用于空状态引导卡片或专注角落小徽章，使用统一风格的精致矢量 SVG 插画，**严禁贴满廉价 Emoji 或粗糙网图**。
