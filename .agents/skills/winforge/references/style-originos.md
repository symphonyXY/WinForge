# 最新 OriginOS 空间光影与原子交互设计体系（1:1 复刻指南）

本手册用于 1:1 复刻 vivo 最新 OriginOS（空间光影、自然柔和质感、原子组件卡片、原子岛胶囊与极度跟手的 Q 弹物理动效），并将其自然落地为 Windows 桌面软件设计语言。

> **实体参考**：动工前务必打开并对照 [OriginOS 光影原子交互样板间](../showcases/originos-atomic-light.html)，直接参考其中的自然弥散光影、原子卡片原位放大展开、原子岛交互与 Q 弹弹簧参数。

---

## 1. 设计灵魂与核心气质

- **自然光影与空间呼吸感**：OriginOS 最迷人的地方在于“有光、有空气、有空间层次”。背景不是死板纯白或死黑，而是柔和流动的**自然晨光/天光/深空弥散光晕**；每一层卡片仿佛自然承接环境光，靠柔和明暗与景深自然拉开层次，而不是用生硬灰线画格子。
- **原子化信息卡片（Atomic Cards）**：把核心功能与实时状态浓缩成一个个精致、圆润、比例和谐的**原子卡片**（支持 `1×1` 小卡、`2×1` 宽卡、`2×2` 主焦点卡），卡片一眼看得懂、直接就能在卡片上轻操作（开关、切歌、启动任务），点开卡片还能**原位平滑放大展开**成完整详情页。
- **原子岛（Atomic Island）**：界面顶部居中或悬浮区承载实时动态胶囊（任务进度、文件拖放、状态通知、快捷控制），平时安安静静，触发时如液滴般丝滑舒展。
- **Q 弹丝滑的物理动效**：相比苹果偏克制利落的回弹，OriginOS 的动效带有更愉悦、轻盈、富有生命力的**柔和过冲与阻尼收尾**——手指/鼠标点哪里，反馈就立刻从哪里荡开，打断反向时永远从当前画面无缝接续，绝不瞬移。

## 2. Windows 桌面端专属适配规范

- **全景光影融合顶栏**：窗口内容与背景弥散光影直通顶部边缘（顶栏高 `46px–50px`），保留右上角精修的极简圆润 Windows 窗口按钮（圆角 `10px` 胶囊微浮风格，关闭键悬停柔和暖珊瑚红 `#F2555A`），兼顾惊艳第一眼与 Windows 顺手习惯。
- **字体与图标（100% 离线内置）**：
  - 优先离线内置气质最贴近 vivo Sans 的圆润现代无衬线字体（英文数字 `Plus Jakarta Sans` / `Inter` + 中文 `HarmonyOS Sans SC` / `Source Han Sans SC`），平滑回退至 `"Segoe UI Variable", "Microsoft YaHei UI", sans-serif`。
  - 关键大数字（温度、进度百分比、专注时间、数量统计）采用大气清朗的轻粗字重（`600`）与等宽对齐，营造“一眼直达”的原子卡片美感。
  - 图标采用**略带温润微弧度、填充与线性克制结合的现代矢量 SVG**，绝不使用系统 Emoji 凑数。

## 4. 原子几何比例与空间节奏

- **更饱满的大圆角基因**：OriginOS 卡片比普通桌面软件更圆润温润：
  - 原子功能卡片：`24px – 28px`
  - 原子岛 / 悬浮工具条 / 主操作胶囊按钮：`999px`
  - 卡片内嵌子按钮 / 快捷块：`14px – 16px`（依然遵守 `外圆角 = 内圆角 + 间距`）
  - 输入框与普通控件：`12px – 14px`
- **网格与呼吸感**：
  - 原子卡片之间保持均匀的 `14px – 16px` 间隙，整洁对齐；
  - 卡片内部留白 `18px – 22px`，信息分主次（左上角简洁图标/标题，核心大号状态或快捷操作居中/右下），**拒绝一张卡里塞满 6 个小按钮**。

## 5. 核心控件与 Q 弹物理动效参数（1:1 手感）

| 元件 | 视觉细节与状态 | Q 弹物理动效 |
|---|---|---|
| **原子卡片原位放大展开** | 悬停时卡片柔和微浮 `translateY(-2px)`，并伴随光标柔和柔光扫过边沿 | 点击卡片后，记录当前坐标与宽高，用 `380ms` 弹性曲线 `cubic-bezier(0.22, 1.12, 0.36, 1)` 原位放大展开为详情面板（背景轻柔柔焦压暗）；点击关闭或按 `Esc` 沿原路丝滑弹回原位 |
| **原子岛（Atomic Island）** | 居中悬浮墨釉/玻璃胶囊，展示当前运行态脉冲点与简洁进度/状态 | 触发事件或点击时，宽高与圆角同步平滑形变展开操作面板（`360ms` 轻微过冲回弹），操作完成自动丝滑收回 |
| **按压回弹按钮 / 原子快捷键** | 饱满圆润胶囊或大圆角方块；悬停微提亮并泛起柔和光泽 | 按下 `90ms` 内柔和压缩 `scale(0.94)`，松手 `320ms` 带轻盈回弹 `cubic-bezier(0.34, 1.45, 0.64, 1)` 弹回 `1.0` |
| **悬浮底部导航 / 工具条** | 独立悬浮玻璃胶囊底座，图标圆润清晰，选中项带高亮柔光气泡 | 切换项时，高亮气泡弹性滑移并略微“液滴拉伸”后轻弹落位，图标轻微弹跳微动 |
| **流畅开关与阻尼滑块** | 开关饱满圆润；滑块轨道宽厚清晰（类似系统亮度/音量条质感，圆角大胶囊填充） | 滑块拖动时如真实阻尼推杆般跟手，拖到尽头有轻微回弹反馈；开关切换瞬间轻柔弹跳 |
| **页面 / 标签切换** | 弱化硬切，强调空间方向感 | 新内容带 `12px` 轻柔位移 + 淡入，卡片列表按极短错峰（每项 `25ms`，总计不超 `100ms`）依次轻盈浮现，不阻塞用户点击 |
